# Lightcurve Format Definition

The purpose of this repository is to provide an example of the lightcurve file formats 
requested as output from the cb2rges pipeline. 

See the notebook example_lightcurve_format_specification.ipynb for a description of the format and 
contents of an event lightcurve file, as well as template code for reading and writing the 
files in Python.  

A simulated example event lightcurve can be found in example_event_lightcurve.fits.
